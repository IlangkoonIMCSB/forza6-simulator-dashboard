# Building a Custom JDM Telemetry App for Forza 6

This guide provides the complete blueprint and master prompt needed to build a native Android telemetry dashboard for Forza Motorsport 6 using a Node.js backend and an Expo (React Native) frontend. 

The design is specifically tuned for a dark, glowing 90s/00s JDM aesthetic—perfect for mounting a secondary device on a sim rig or dashboard to recreate the feel of classic aftermarket gauge clusters or an R34 Multi-Function Display.

---

## 1. System Architecture

The project relies on a two-part monorepo structure to capture the UDP stream and push it to the mobile client in real-time.

* **The Game (Forza 6):** Broadcasts a binary data packet over UDP (port 5300) to the local network at 60Hz.
* **The Backend (Node.js):** Listens for the UDP packets, parses the specific byte offsets (Little-Endian format) for speed, RPM, gear, and map coordinates, and packages them into clean JSON.
* **The Bridge (WebSockets):** Uses `socket.io` to stream the JSON data instantly without HTTP request overhead.
* **The Client (Expo / React Native):** A native Android app utilizing `react-native-reanimated` for zero-jitter, hardware-accelerated gauge sweeps, pulling the live data and rendering the UI.

### Phase 1: The Node.js Backend (`/server`)

Create a functional Node.js application (`index.js`).

Requirements:
1. Install: `npm i dgram socket.io`
2. Implement a UDP socket using `dgram` listening on port `5300` for 'Data Out'.
3. Use the known Forza Motorsport (Car Dash) packet structure to parse the raw 311/324-byte binary stream (Little-Endian format). Include logic to parse these specific offsets:
   - `isRaceOn` (Int32LE, Offset 0) - Filter only active race data.
   - `engineMaxRpm` (FloatLE, Offset 12)
   - `engineIdleRpm` (FloatLE, Offset 16)
   - `currentEngineRpm` (FloatLE, Offset 20)
   - `speedKmh` (FloatLE, Offset 256, then * 3.6 for KM/H)
   - `gear` (UInt8, Offset 319) - (0=R, 1-6=Forward).
   - `positionX`, `positionY`, `positionZ` (Floats) for mapping.
4. Set up `socket.io` to create a WebSocket server on port `4000`.
5. Broadcast the clean JSON telemetry packet to all connected clients 60 times per second.
